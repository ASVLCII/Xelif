# Xelif v0.1.2 — Sort button

Sort files directly from the toolbar beside Search and Commands.

- Choose Name, Date modified, Type, Size, or Natural ordering.
- Set Ascending or Descending independently; dots show both active choices.
- Use the mouse or Up/Down and Enter. Escape or clicking outside dismisses the menu.
- Keep the same file focused when the list reorders. The dropdown adapts to narrow panels and stays within the screen.
- Undo now refuses a file or directory that was replaced after its undo journal was recorded. Partial retries retain the original identity.

## Downloads

Download the native archive matching your platform, extract it, and run `xelif`
(`xelif.exe` on Windows). Windows x64 uses `windows-amd64`; Windows ARM uses
`windows-arm64`. macOS and Linux archives are also provided for both architectures.

`SHA256SUMS.txt` and `BUILD-PROVENANCE.json` identify the uploaded artifacts and
their exact source commit and CI packaging run. Native builds are not code-signed
or notarized.

This is a GitHub release. npm `latest` is still `0.1.0`, which does not contain
the new Sort button; npm/Bun global installation commands will continue to install
that version until a separate npm publication.
