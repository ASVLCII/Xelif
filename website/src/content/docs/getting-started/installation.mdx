## Install Xelif with npm or Bun

The published preview is **`0.1.0-preview.1`**, with native executables for Windows, macOS and Linux on x64 and ARM64. Choose one package manager:

```sh
npm install -g @asvlcii/xelif@preview
# or
bun add -g @asvlcii/xelif@preview
```

Then run:

```sh
xelif
# Or open a particular folder:
xelif "/path/to/a folder"
```

Install Node.js 22+ for the global launcher, including when installing with Bun. No Go compiler is needed. Leave optional dependencies enabled so the package manager can select your native executable. A Nerd Font is recommended for icons. Run the same installation command again to update to the current preview.

Both commands use the same npm registry package; there is no separate Bun account requirement. The package has no postinstall scripts or startup downloads.

If another installation opens, inspect `Get-Command xelif -All` in PowerShell or `command -v xelif` on Unix. An existing development launcher may take precedence.

:::caution

Xelif's npm package is a preview, not a stable release. The legacy scripts and other package-manager commands in the **Install upstream superfile** section below install [yorukot/superfile](https://github.com/yorukot/superfile), not Xelif.

:::

## Build Xelif from this checkout

Install [Go](https://go.dev/doc/install), then run one of these commands from the repository root:

```bash
# macOS or Linux
./build.sh
```

```powershell
# Windows
go build -o bin/spf.exe
```

The development binary intentionally remains named `spf` for superfile compatibility.

## Install upstream superfile

First make sure you have the following tools installed on your machine:

- [Any Nerd-font ](https://www.nerdfonts.com/font-downloads), and set the font for your terminal application to use the installed Nerd-font

:::tip

If you don't install `Nerd font`, superfile will still work, but the UI may look a bit off. It's recommended to disable the Nerd font option to avoid this issue.

:::

### Installation scripts

Copy and paste the following one-line command into your machine's terminal.

### Linux / macOS

With `curl`:

```bash
bash -c "$(curl -sLo- https://superfile.dev/install.sh)"
```

Or with `wget`:

```bash
bash -c "$(wget -qO- https://superfile.dev/install.sh)"
```

Use `SPF_INSTALL_VERSION` to specify a version :

```bash
SPF_INSTALL_VERSION=1.2.1 bash -c "$(curl -sLo- https://superfile.dev/install.sh)"
```

### Windows

With `powershell`:

```bash
powershell -ExecutionPolicy Bypass -Command "Invoke-Expression ((New-Object System.Net.WebClient).DownloadString('https://superfile.dev/install.ps1'))"
```

:::note

To uninstall, run the above `powershell` command with the modified URL:

`https://superfile.dev/uninstall.ps1`

:::

Use `SPF_INSTALL_VERSION` to specify a version :

```bash
powershell -ExecutionPolicy Bypass -Command "$env:SPF_INSTALL_VERSION=1.2.1; Invoke-Expression ((New-Object System.Net.WebClient).DownloadString('https://superfile.dev/install.ps1'))"
```

With [Winget](https://winget.run/):

```powershell
winget install --id yorukot.superfile
```

With [Scoop](https://scoop.sh/):

```bash
scoop install superfile
```

## Community maintained packages

[![Packaging status](https://repology.org/badge/vertical-allrepos/superfile.svg)](https://repology.org/project/superfile/versions)

> Sort by letter

### Arch

###### Builds package from sources

```bash
sudo pacman -S superfile
```

###### Builds most recent version from GitHub

```bash
yay -S superfile-git
```

### Homebrew

Install [Homebrew](https://brew.sh/) and then run the following command:

```bash
brew install superfile
```

### NixOS

###### Install with nix command-line

```bash
nix profile install github:yorukot/superfile#superfile
```

###### Install with flake

Add superfile to your flake inputs:

```nix
inputs = {
  superfile = {
    url = "github:yorukot/superfile";
  };
  # ...
};
```

Then you can add it to your packages:

```nix
let
  system = "x86_64-linux";
in {
  environment.systemPackages = with pkgs; [
    # ...
    inputs.superfile.packages.${system}.default  ];
}
```

### Pixi

Install [Pixi](https://pixi.sh/latest/) and then run the following command:

```bash
pixi global install superfile
```

### X-CMD

[x-cmd](https://www.x-cmd.com/) is a **toolbox for Posix Shell**, offering a lightweight package manager built using shell and awk.

```sh
x env use superfile
```

## Start superfile

After completing the installation, you can restart the terminal (if necessary).

Run `spf` to start superfile

```bash
spf
```
