# Xelif 是什麼？

Xelif 是以鍵盤操作為主、衍生自 [yorukot/superfile](https://github.com/yorukot/superfile) 的終端機檔案管理器。它保留 superfile 精緻的多面板介面，並加入適合大型專案的搜尋與安全操作流程。兩個專案皆使用 [Go](https://go.dev/) 與 [Bubble Tea](https://github.com/charmbracelet/bubbletea) 打造。

## 相容性與來源標示

執行檔仍稱為 `spf`，設定與資料目錄、主題、快捷鍵及 Go 模組路徑也保留 superfile 名稱，以維持相容性。上游圖稿、套件、社群連結與歷史文件仍歸屬於 [superfile 及其貢獻者](https://github.com/yorukot/superfile)。Xelif 沿用此儲存庫的 MIT 授權。
